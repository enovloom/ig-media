ChatGPT のリサーチで見つけたネタもここに足す。

## F1 建前と本音

店長の一言 → スタッフの本音
- 「何か困ってること、ある？」→ 本音「困ってるのは、その質問です」
- 「みんなの意見を聞きたい」→ 本音「どうせもう決まってるやつ」
- 「前の店長のやり方は一回忘れようか」→ 本音「前の店長、神だったんですけど」
- 「気軽に相談してね」→ 本音「気軽に相談した結果、30分説教された人を知ってます」
- 「今月、あと少しだから頑張ろう」→ 本音「先月も"あと少し"でした」
- 「任せるから、好きにやっていいよ」→ 本音「（好きにやったら怒るやつ）」
- 「最近どう？」→ 本音「何を答えたら正解ですか」
- 「失敗してもいいから」→ 本音「失敗した人の末路、見てました」
- 「数字は気にしなくていい」→ 本音「じゃあ毎朝の売上報告は何ですか」

スタッフの一言 → 店長の本音
- 「前の店長はそんなこと言わなかったです」→ 本音「前の店長、今どこで何してるか知ってる？」
- 「わかりました！」→ 本音（店長）「その"わかりました"、3回目」
- 「お客様に押し売りしたくないんです」→ 本音「…それ、本当は何が嫌なんだろう」（F4 につながる）
- 「辞めたいわけじゃないんですけど」→ 本音「その前置き、9割辞めるやつ」

案内先の note: スタッフの本音を聞く関わり方

## F2 店長あるある
- 休みの日に店のLINEが鳴ると、通知の1行目で心拍数が分かる
- 新人に「いつでも聞いてね」と言った日に限って、一番忙しい
- シフト表を作り終えた5分後に「すみません、来週なんですけど…」
- 面談で「何か言いたいことある？」→ 沈黙 → 帰り際の廊下で全部言われる

## F3 声かけ Before / After
- ✕「なんでやらなかったの？」→ ○「どこで止まった？」
- ✕「大丈夫？」→ ○「今日いちばん大変だったの、どこ？」
- ✕「前にも言ったよね」→ ○「前に言ったこと、分かりにくかった所ある？」

## F4 1分ドラマ

### 新店長ドラマ 第1話（作成済み、未投稿）
誰も歓迎しなかった新店長。B 型。`episodes/drama-ep1.json`、queue `2026-11-05-2100_drama_shinten1`。
本人の感想（2026-10-31）:「AIすぎる」「何もおもろない」。静かな会話から始まり、事件と見え方が変わる瞬間がなかった。

### 辞めます（帰り際ノート）
B 型。冒頭の事件と、見え方が変わる瞬間を入れた案。
1. ミオが白い封筒を受付台に叩きつける「辞めます」
2. 固まる店長（着任して、まだ1週間）
3. ミオ「数字、数字って。お客さんの顔、見てないじゃないですか」
4. 店長、小さなノートを差し出す「…見てますよ」
5. ノートの中身（字幕で）「田中様 帰り際、笑顔なし。膝が痛む？」 ミオの表情が変わる
6. ミオ「…これ、全部？」 店長「数字は、笑顔の結果なんで」
7. 最後の画面「お客様の帰り際ノートの書き方 → note」

### 教えたのに、やらない新人（ChatGPT の企画案、2026-10-31）
B 型。次の店長候補をどう育てるか。2本目の note の実例（新人が指名提案を押し売りだと感じ、育成担当が関わり方を変えた）が着想元。人物と会話はフィクション。
1. 冒頭の対立: 育成担当が店長に訴える「何回も教えました。なのに、あの子はやらないんですよ」
2. 予想外の問い: 店長は新人を叱らず、育成担当に聞く「その子がやらない理由、本人に聞いた？」
3. 感情の転換: 新人は継続トレーニングの提案を「押し売り」だと感じていたと分かる。育成担当は、教え方以前に相手の考えを分かっていなかったと気づく
4. 結末: 育成担当と新人が「お客様が自分で必要性を判断できるには」を一緒に考え始める。全部は解決させず、小さな変化で終える
- note への導線: 「新人のやる気を責める前に、何を確かめ、何を任せるか」
- 測るもの: 再生に加えて、プロフィールへのアクセス、note の閲覧、購入。再生が伸びても note に来なければ、見ている人と商品の相手がずれている

### A 型の候補（拡散の検証用）
- 手柄を横取りする先輩 → 新人の記録が証拠になる → 店長が公平に評価し直す（店長が「裁く人」でなく「仕組みを直す人」として出る形にする）
