## できないこと（エンジンの制約）
- **感情や話し方を指定する機能はない**。「穏やか」「明るい」は、抑揚の強さ・高さ・わずかな速さ・行間の間の組み合わせで近づけただけ
- **語尾の上がり下がりは指定できない**。声のデータで決まる。測ると、女性の声は C・D とも文末で下がり（D の方がやや大きく下がる）、明るめの語尾にはなっていない。男性は B の方が A より語尾が平ら
- 男性の声は1種類だけなので、A と B は同じ人の声で、話し方だけが違う
- 読み方（アクセント、「OK」の読み）はエンジンの辞書まかせで、直すには台本の表記を変える必要がある
- 2010年代の HTS 方式の声なので、今のニューラル音声よりも機械らしさが残る

## 技術的に確認した項目
- 4本の BGM なしの音声が同じ大きさ（−21.5 LUFS）で、音割れしていないこと
- 4本の動画が 1080x1920・30fps・音あり・−14 LUFS 前後で、`check.js` の警告がないこと
- 各動画で、6行の声が予定の位置にあること（声の区間 −13.8〜−19.0 dB、行間は BGM だけでそれより小さい）
- 図や文字が、その言葉を言い始める前後0.3秒以内に出ること（`build.py` がそれぞれの声の区切りから組み立てる）
- 落ち着き版と明るめ版で、抑揚の幅・高さ・行間・全体の長さが狙いどおりに違うこと（上の表）
- 語尾が消えていないこと（語尾0.3秒の音量が行全体と ±1dB 以内）

## 実際には聞いていない項目
- **4本とも耳で聞いていない**。自然な日本語に聞こえるか、語尾まで聞き取りやすいか、落ち着き版が眠そうでないか、明るめ版がうるさくないかは、上の数値から推測しただけ
- 機械らしさの度合い、アクセントの不自然さ
- 動画を再生したときに、声と画面が合って見えるか
- どの声が店長向けに合うか（本人が聞いて選ぶ）
