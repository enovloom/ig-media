# ネタ帳

頭脳がここから話題を選び、使ったら「使用済み（日付）」を付けます。人が書き足してもOKです。
形式: `- [ ] 話題 — 場面のメモ`（使用済みは `- [x] … （使用済み YYYY-MM-DD）`）

## そもそも、なぜ育てるのか
やり方の前にある、店長自身の「なぜ」に触れる回。`brain/brand.md` の「届けたい人の『なぜ』」とセットで使う。発信者本人の動機や体験は、`brand.md` に書かれたこと以外は作らない。
- [ ] 休みの日なのに、店から LINE が 5 件 — 育てるのは、店長が休める店にするため。まず 1 つ、自分がいなくても決められることを作る
- [ ] スタッフに「なんで私に任せるんですか？」と聞かれて答えられない — 店の都合だけでなく、本人に任せたい理由を一言で言えるようにしておく
- [ ] 「店長、楽したいから任せてるんでしょ」 — 楽になりたい、は悪くない。でもそれだけだと丸投げに見える。本人に何を経験してほしいかも伝える
- [ ] 失敗させたくなくて、つい口を出す — 守りたいのは本人か、自分の評価か。一度だけ自分に聞いてみる
- [ ] オーナーに「人が育たないね」と言われた — 評価のための育成になると、急いで答えを渡してしまう
- [ ] 育てた人が辞めると言ってきた — 引き止める前に、自分は何のために育てていたかを思い出す
- [ ] 新人に「店長は、なんで店長やってるんですか？」と聞かれた — 店長自身のやりたいことが言えると、任せる理由も伝わる
- [ ] 2 番手が育ったら、店長は何をする？ — 空いた時間で何をしたいかを先に決めておく
